# README figures

<!-- Editor: Jialei.He -->

The figures in this directory are rendered from the original PDFs for
Figures 1-3 of the accompanying manuscript and are used on the repository
landing page.

- `contilnn_motivation.png`: Figure 1, ordered-slice restoration and slice-axis
  formulation;
- `contilnn_architecture.png`: Figure 2, ContiLNN–RWKV architecture and training
  supervision with a frozen 2D backbone;
- `qualitative_ct_mri_pet.png`: Figure 3, two restoration examples per modality
  with matched regions of interest, arrows, and error-reduction color scales.

The qualitative panel contains rendered, de-identified dataset case labels but
does not include raw volumes or medical-image headers. Repository licensing
does not alter the source datasets' terms; redistribution and reuse remain
subject to those terms.
